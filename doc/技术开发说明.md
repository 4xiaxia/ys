## 三、七列表 Row 字段表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `duration` | string | 固定 `待程序预估` → 程序替换为 `预计 M:SS—M:SS` | 时间区间 |
| `stage` | string | 枚举：题目/分析/解答/答语/总结 | 教学环节 |
| `notes` | string | 非空 | 教学重点/易错点/旁注（不上画布） |
| `speech` | string | 非空，TTS可读 | 口播稿，禁止LaTeX/分数符号 |
| `board` | string | 可为空字符串 | 板书内容描述，含`【x%,y%】`坐标或`[区域]`标记 |
| `actionSpec` | array | 可为空数组 | 板书动作稿，每项 `{cueText, action}` 或 `{cueText, capabilityGap}` |

### actionSpec 单项结构
```js
// 已注册工具动作
{
  cueText: "本行speech中的触发原文",
  action: {
    tool: "rough-notation|rough-line|rough-arrow|draw|...",
    action: "underline|highlight|...",   // 工具子动作
    region: "question|analysis|solution|summary",
    order: 1,    // 全表唯一正整数，串行
    target: { exactText, occurrence },   // rough-notation 用
    startCoord: "x%,y%",                 // draw/rough-* 用
    intent: "动作:画图; 时长:3s; ...",   // draw 专用
    options: { colorId: "red" }
  }
}
// 能力缺口（工具做不到时）
{
  cueText: "触发原文",
  capabilityGap: { id: "能力ID", need: "需要什么" }
}
```
