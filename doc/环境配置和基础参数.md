## 基础参数

### 画布规格
| 参数 | 值 |
|------|---|
| 设计宽度 | 1726px |
| 设计高度 | 980px |
| 坐标单位 | 百分比（0–100） |
| 参考表稿宽 | 1892px |
| 参考表稿高 | 1044px |

### 口播参数
| 参数 | 值 |
|------|---|
| 语速基准 | 170字/分钟 |
| 单字时长 | ~353ms |
| duration格式 | `预计 M:SS—M:SS` |

### API 配置（用户自填，不写死）
| 参数 | 存储位置 |
|------|----------|
| apiKey | localStorage `qinghuabu.userApiConfig.v1` |
| endpoint | 同上 |
| model | 同上 |

### 请求超时
| 端点 | 超时 |
|------|------|
| `/api/recognition/problem` | 30s |
| `/api/agent-b/board-draft` | 60s（旧v1） |
| `/api/agent-b-v2/generate` | 90s |
| 前端 fetch 侧 | 95s（AbortController） |
