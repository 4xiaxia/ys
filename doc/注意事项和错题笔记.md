## 一、开发注意事项

### 画布截图
- `html-to-image` 截图前必须等 `document.fonts.ready` + 两次 `nextTick`，否则手写字体未加载出现黑块/乱码。
- 截图失败不得阻断主流程，降级为空串继续（`service.js` 和 `Step1Entry.vue` 均已处理）。

### API Key 管理
- 所有 `apiKey/endpoint/model` 只走 `userApiConfig.js`，不得新建其他存储路径。
- 服务端代理（vite.config.js inline + agentBV2ProxyPlugin.js）均从请求体读取，不读 process.env。

### Agent B 输出校验
- `contract.js` 校验顺序：normalizeRows → 第一行必须是题目 → 读题行board必须为空 → 逐行字段校验 → 必须有分析行 → 几何题必须有分析区画图动作。
- 板书数学校验（boardMathPolicy）默认 `hardFail: false`，只警告不抛错，保证七列表能出。
- 模型有时漏写 actionSpec，contract 自动补空数组，不要手动修复模型输出。

### 旧路径（V1）不要碰
- `BoardParamDraft.vue` / `agentBDraft.js` / `SolutionReviewPanel.vue` 是旧双阶段路径，当前不在主路由。
- 不要从这三个文件里复制逻辑到新路径，避免引入废弃行为。

### 知识库匹配
- `agentBKnowledge.js` 用 bigram/trigram 重叠度匹配，精度偏低，短题文命中率不高。
- 匹配失败不报错，返回空数组，Agent B 按题目自行判断。
- CSV 文件 `?raw` 方式导入，每次冷启动都要重新解析，无缓存开销问题（文件 ~81KB）。

## 三、口播规范红线（来自 doc/口播+板书必看.md）

❌ 禁止在口播中出现：
- KaTeX / LaTeX / Markdown 语法（`$`、`\frac`、`\(`等）
- 斜杠分数（`5/8`、`1/2`）
- 符号原形：`x`（乘号）、`×`、`/`、`÷`
- 小数读错：`3.14` 应为 `三点一四`（逐位读）

✅ 分数读法：`8分之5`（分母在前），禁止写中文数字（`八分之五`）
✅ 未知数 x：口播写 `艾克斯`；乘号 x：口播写 `乘以`
✅ notes 中必须注明每个 x 的含义

## 四、板书规范红线（来自 doc/口播+板书必看.md）

❌ 禁止：
- 分数用 `/`（如 `5/8`）
- 乘号用 `×`（板书用小写 `x`）
- 中文放进 KaTeX `\text{}`

✅ 分数必须用 `\frac{5}{8}`（上下结构）
✅ 带分数：`1\frac{1}{2}`
✅ KaTeX 只用于分数/根号/上下标/公式结构；中文直接写
